# 是该感动还是该感伤呢？

<div class="article-meta">第 178 篇 · 2011-04-05 14:16:57</div>

<a class="source-link" href="http://nteswjq.blog.163.com/blog/static/12699812011352145215" target="_blank" rel="noreferrer">原博客链接</a>

我记得很久以前有一次在国内和一个美国来的朋友吃饭，电视里正播着某地方领导人不以权谋私的新
闻，然后朋友问我那是什么意思，我突然觉得很无语。

金哨孙葆洁3句反问令人震撼 徐明感慨:我们敬重您
http://sports.sina.com.cn  2011年04月04日23:07  新浪体育
新浪体育讯　中超揭幕战，客场作战的大连实德队提出，要请外籍裁判的话就请日本的，如果中国
裁判执法，只有一个候选人，他就是“孙葆洁”。于是按国际足联规定已经到了退役年龄的孙葆洁再次出
现在中超赛场上，而且执法了中超的揭幕战。
孙葆洁的执法不可能不成功，不是他业务真的到了无可挑剔的地步，赛中我们可以清楚的看到大连
实德队的阎嵩在与他争论，但是这种争论限于业务，双方球员对他的公正性毫不怀疑。首轮比赛后BTV
在其王牌体育节目《足球一百分》中请来了孙葆洁，在中国足球打假扫⿊的风暴中，几个⽚段和简单的
话语让我们看到了这个7届金哨带给我们的感动。
在这个⽚子，我们回到了2001年。当时广州吉利俱乐部总经理在退出足坛的新闻发布会上说，当
年的10月份他到中国足协投诉裁判，其中就包括当场比赛的边裁刘铁军，当时中国足协的联赛部主任杨
一民告诉他，“我可以告诉你，在中国现在的裁判中有两个人是不可能收受贿赂的，一个叫刘铁军，一个
叫孙葆洁。”
尽管有从不收受贿赂的说法，但是在当年浙江绿城掀起的扫⿊风暴中，当年刚刚被评为金哨的孙葆
洁却出人意料的出现在所谓的“⿊哨”名单中。名单被媒体公开后，孙葆洁面对镜头时的几句话让人至今
难忘，“我不知道是什么动机，我不知道为什么要混淆视听、颠倒⿊白，我不知道背后有什么目的，绿城
俱乐部的老板宋卫平先生也说了，孙葆洁先生是不收钱的。”说到激动处，他掀了掀自⼰的衣服，说出了
掷地有声的三个“如果我有钱”很从容，但是现在听起来仍然震撼人心：“如果我有钱？我不这样穿。如果
我有钱？我住大房子。如果我有钱，我可能会过更好的日子。但是我想，我不羡慕别人！”
因为公正，孙葆洁最讲究公正的领域获得了最大的尊重。当确认参加中超开幕式的大场面时，作为
客队大连实德队点名要求孙葆洁进行执法，而主场作战的广州恒大队也欣然接受，这是对他公正性的最
大认可。当他如约出现在比赛现场时，大连实德俱乐部的投资人徐明在握住孙葆洁的手时称呼是“孙老
师”，一句“我们都敬重您”的话语让人体验到中超裁判带给我们的另外一种震撼。
面对BTV主持人关于出淤泥而不染的提问，孙葆洁提到了感恩一词，“首先我是一名教师，因为清
华大学对教师的要求很高。我也是国家培养大的，学费都不要，还有伙⻝补贴，我只需要从家里拿一点
钱就可以生活了，所以我对祖国抱着一颗感恩的心，我深知自⼰所肩负的社会责任。其次我是足球工作
者、是体育工作者，我知道运动员那种付出，我非常尊重他们。”
(水⾳)
