# 【转载】在8点20分打假央视3.15晚会

<div class="article-meta">第 439 篇 · 2013-03-17 13:16:30</div>

<a class="source-link" href="http://nteswjq.blog.163.com/blog/static/1269981201321711630353" target="_blank" rel="noreferrer">原博客链接</a>

作者：李铁

打假这么严肃的事，却被何润东给搞笑了场。故事是这样的：在央视广告部和经营等盈利部门的主导之下，一年一度的央视3.15晚会又粉墨登场啦。去年他们讨伐的是⻨当劳，说是做出来的盐焗鸡翅，放了一个多小时居然还没扔掉，实在太不象话。央视记者卧底了几个月，终于抓到了一个⻨当劳员工把掉在地上的⽜肉饼重新夹进汉堡的罪行。今年，他们把炮口对准了苹果，问题苹果后盖保修的问题。然后，央视又让一帮大V拿着苹果设备发微博来讨伐苹果。这时候出了点小纰漏，情形有点像我小时候抄作业，把同桌的名字也给抄进去了。何润东一不留神，把“8点20分发”，也写了进去，成了“猪一样的队友”。好几个在8点20分发微博声讨苹果的名人也被挖了出来。尽管何润东后来发微博称，此事是因为微博被盗号，但这个解释实在太苍白，节操掉了一地，一轮微博吐槽汹涌而来。尽管另几个大V表示情绪稳定，但他们的⾎压是否真稳定，只有天知道。大伙⼉之所以觉得这事可笑，原因就在于，在一个毒奶粉、地沟油层出不穷的地界，央视的3.15打假晚会去义正言辞地讨伐⻨当劳卖失去口感的鸡翅，苹果后盖的保修，实在有点滑稽。难道你没注意到，连@留几手 这样獐头⿏目的网友都义正言辞地讨伐苹果了，其中必有蹊跷嘛。更正经的原因就在于，3.15打假，已经沦为了一项生意，打假成了一些媒体勒索广告，打击竞争对手的⿊手段。3.15打假，有多少罪恶借汝而行？当我们在看央视的这台打假晚会的时候，我们居然还看到了一些企业的广告。这些出钱的企业，它到底打不打呢？有知名媒体人实名爆料，在这些打假晚会的背后，还有长长的一摞广告客户，有一堆VIP客户的保护名单。这种选择性的打假，有多少公信力？这到底是打假，还是勒索、碰瓷？在打假方面，央视早有劣迹在先。2011年7月10日，央视的《每周质量报道》节目曝光达芬奇家居涉嫌伪造产地，材料也并非实木，一时间达芬奇遭网民声讨。但数月之后，经过《新世纪》等媒体扎实的调查，这是一桩地地道道的诬陷。是央视内部人员和公关公司参与作伪证的敲诈和抹⿊，相关人员也已经被清除。然而遗憾的是，由于央视独有的平台和影响力，之后的澄清报道远没有之前的抹⿊新闻有影响力。央视自然也不会道歉达芬奇家具也一蹶不振，欲哭无泪。除了谴责某些媒体的无良，我们更需要反思的是这种依靠媒体，依靠一台晚会来打假的畸形生态。对于各种假货和质量问题，由于体制内缺乏正常的监督和管理机制，人们把打假的希望寄托在了媒体曝光上面，这直接造成了媒体在打假领域的畸形繁荣。由于媒体本身就有企业和盈利的属性，当它以打假之名，手握着巨大话语权的时候，一门以打假为名的生意由此诞生。一个正常的社会，对付假货，自然有正常的体制，打假是体制内的一项日常工作。各个部门本该各司其职，层级清楚、一个萝⼘一个坑的管事。如果我们把打假的工作都交给媒体来做，一切就会搞成一场群众运动，一场广场狂欢。一个占据绝对传播优势的电视台，每年举行一台打假晚会，这就是一场民粹的狂欢。它在台上喊着无比正义的口号，煽动起人们对质量问题的愤恨与情绪，勾勾手指头，人们就乖乖地跟着它走了，跟着它喊打喊杀。喧嚣之中，人们可曾发现了领头者夹带的私货？对于群众运动的煽动者来讲，玩弄群众并非没有风险。群众运动的特点就是难以掌控，稍不留神就会擦枪走火，原本被忽悠的群众可能随时掉头向自⼰扑来。除非领头的人能保持绝对的信息和舆论控制力。但这一点，在网络时代，在信息源多中心的微博时代，已经做不到了。此次8点20分事件就是最好的例证。因为何润东的一次低级失误，让舆论控制背后的小九九被暴露在了广场上。随着8点20分事件的迅速发酵，不单是央视，那些参与了围殴苹果的微博大V，都忙着狼狈的在地上捡节操呢，这一夜，后遗症很重。这不能不说是一件好事，至少能让人们明白，那些一手拿着广告胡萝⼘，一手拿着打假大棒的强势媒体，是不靠谱的。如果咱们把打假的希望都寄托在这些媒体身上，那就只有被卖拐的份⼉。另外，不仅这种手握大权的官媒打假不靠谱，即便是更加开放自由的微博和网络，咱也不能把打假的希望都寄托在那⼉。媒体是社会监督的一部分，它有它的功能，也有它的局限，它只是整个社会治理和监督的一个环节。我们要做的，是完善整个打假的制度链条，让打假成为一项制度性的日常事务。否则，把一年的打假活，都堆到一天的晚会上，只会让这个晚会变成一个更大的假货哥斯拉。为了纪念8点20分这个历史性的时刻，我决定在3月17日早上8点20分发出这篇文章。@ 何润东
