# double free---golf

<div class="article-meta">第 136 篇 · 2011-01-14 05:10:59</div>

<a class="source-link" href="http://nteswjq.blog.163.com/blog/static/12699812011014529942" target="_blank" rel="noreferrer">原博客链接</a>

昨天打了场球，虽然推杆很烂（37推），成绩不算好（78），但没有double。

现在我打球的最高追求就是double free，有点像投资，尽量少犯大错。

只要能做到这一点，成绩总还是过得去。

过去的统计表明，我大概一年只有一场球能做到double free，连打70杆的那场球居然也是有一个

double的。

这也说明只要打球，不犯错是很难的，少犯且不致命最重要。
