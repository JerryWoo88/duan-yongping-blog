# 【转载】回头

<div class="article-meta">第 407 篇 · 2013-01-14 11:44:05</div>

<a class="source-link" href="http://nteswjq.blog.163.com/blog/static/1269981201301411445810" target="_blank" rel="noreferrer">原博客链接</a>

南周事件就这样告一段落，我本以为还会发生更多的事。《环球时报》针对此事发的第一篇没有底线的

社论里有这么一段话：在一个真正动荡的社会，某个人自焚，某个小群体抗议，甚至在网上编个谣言，

都说不准成为一个惊人的开始，但现实的中国是蓬勃发展、不断改革的，那个“要出大事”的中国是一些

人凑到微博上编出来想出来的。       我本以为接下来还会出什么大事。       我一直在微博上看着这件

事情的进展。我看到各家媒体支持得委婉而低调，姚晨李冰冰发出了比较高级的暗号，韩寒的文章转为

祷告，李承鹏的文章迅速被操，人民日报竟然讲了人话，怀疑号被盗，而胡编一如既往地给主子舔着屎

尿。第二天各大报社被集体强暴，新京报反抗，于是差点死掉。最后，所有人都被戴上了避言套。

在我们国家，所有公共事件都是这样的流程。       这件事情很快就查出了真凶，一切都是境外势力惹

的祸，官方没有任何错误。我们的大禹先生从四千年前就开始治水，一直治到两千年前还没有治完，只

有境外势力能制造这么大的水。       我经常想，为什么承认一次错误就这么难。治大国若烹小鲜，世界

上所有事情都是相通的。一个人犯了错误，旁人给他指点出来，是满肚不爽的人多，还是虚心接受的人

多？所以这才有了小人和君子之别。《论语》里面说“小人之过也必文”，文就是粉饰，小人犯了错误，

第一反应永远是拒绝承认同时给自⼰找借口，比如开车的时候翻车了，说是闪电给电的。而“君子之过如

日月之⻝，过也，人皆见之，更也，人皆仰之”，君子从不掩饰自⼰的错误，所有人都看得见，改正了错

误，所有人都仰望他。       一个更有感触的例子是学校跳楼事件。可能是中国教育给学生的压力太小，

以至于学生都觉得生活不刺激，于是纷纷跳楼玩。每当有学校发生跳楼事件的时候，学校做的第一件事

永远是封锁消息，然后找个借口。我们高中不久前就发生过跳楼事情，学校的论坛开始删帖、封号，然

后学校告诉外界这个孩子在阳台上系鞋带不小心掉下去了。所有学校都是这么做的，无一例外，他们这

么做目的不过是怕毁了自⼰名声。设想一下，某天有个学校有人跳楼了，这个学校没有封锁消息，没有

删帖封号，没有阻⽌媒体前来采访，不仅不拒绝，还通过媒体之口向全社会承认自⼰的错误，承担起属

于自⼰的那一部分责任。我确信如果有学校这么做，这个学校的名声不仅不会毁掉，反而会瞬间赢得更

大的尊重。如果有这么一个学校出现，它在我心里的地位会瞬间超过中国政府。       治校如此，治国不

也是同样的道理吗。如果有关部门能放下那不可一世的姿态，勇敢地承认自⼰在南周事件里的错误，我

一定会瞬间对它肃然起敬，我会瞬间觉得它从一庹史变成了一朵花。只可惜没有，至少在我亲眼所见的

这十年里，这个国家没有做过一件能让我对它肃然起敬的事情。       ⽑主席说，我们的成就和错误是九

个指头和一个指头的关系。以今天的情况看来，⽑主席不懂数学，代数没学好，几何图形更没学好，因

为我觉得我们的成就和错误实际上是拳头和手掌的关系。经常听到很多人说，我们现在能吃饱饭不就是

成就吗？这种观点的最著名持有者就是李敖，李敖先生说，今天的中国最大的功劳是它养活了我们十几

亿人，我们应该感谢它。其实美国第二任总统杰斐逊早就说了，让人民吃饱饭是一个政府最基本的职

能，这根本不能算作成就，也根本不值得炫耀。更何况我们的国土上吃不饱饭的人还大有人在。       我

们国家牺牲掉一切所换来的那点经济发展被吹得天花乱坠，而对人民的不公和苦难只字不提，我们只提

美国发生枪击案了，我们只提印度少女被强奸了，结论是民主制度不好。而今天的所有错误，我所见到

的，他们没有承认过一个。历史上的所有错误，我所了解的，他们更没有承认过一个。政府是不会有错

误的，我们有的只是会吐三昧真火的电焊工人和压垮大楼的一群麻雀。在中国活着不容易，因为你要时

刻准备着，准备横眉冷对千夫指，俯首⽢为替罪⽺。在中国活着不容易，在中国这⽚土地上活着的小动

物们也不容易。       所以我想问，连一个错误都从来不承认的国家，它又怎么可能开放言论和新闻。一

旦开放了言论、新闻、出版，你就会瞬间了解到他们更多的错误、谎言和真相，这是在自掘坟墓。所以

在改革制度之前，我们想要的那些和我们息息相关的所有东⻄都不会有，言论自由、新闻自由、出版自

由、电影分级、素质教育、干净的街道、蔚蓝的天空，等等。我们国家现在最需要做的事情，不是在

2049要超过谁，而是要向1949之后所有愧对的人民低头认错。用《一代宗师》里的话说，老猿挂印，关

隘不在挂印，在于回头。社会主义建设，关隘不在建设，在于回头。一个对历史没有反思的国家，一个

不敢认错的国家，超越谁，复兴谁，所有都是空谈。       另外，这几天空气又糟糕了，很可能是因为境

外势力尤其是美国在我们国家投放大量PM 2.5，请大家小心。
