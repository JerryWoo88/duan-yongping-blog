# 零输豪！

6场连胜，还有个绝杀，真是绝了！

零输豪！阿豪末节狂砍12分 逆转17分谁能阻挡纽约

http://sports.sina.com.cn  2012年02月15日11:02  新浪体育微博

新浪体育讯　用5场精彩绝伦的比赛掀起“林风暴”之后，林书豪(微博)在今天率领纽约尼克斯杀到

了多伦多，挑战弱旅多伦多猛⻰。最终，纽约尼克斯以90-87客场击败了猛⻰。林书豪上场43分钟，20

投9中得到27分2篮板11助攻1抢断，完全统治了比赛。

视频-林书豪0.5秒3分绝杀完整版 林风暴再续惊世传奇媒体来源：新浪体育 　　显然，今天的猛⻰

对林书豪做了充分的研究——这也是很正常的现象，在昨天，多伦多市内的巨幅广告牌上打出的广告

是：“SEE LINSANITY LIVE(来现场看林风暴吧)。”这种行为无异于皇家马德里在自⼰的地盘上打出广

告：“来看梅⻄吧。”所以，作为主场球队的猛⻰，心中怀有何种情愫，已是不言自明。

在本场比赛初期，林书豪还是非常小心的，今天是大哥阿玛雷-斯塔德迈尔复出的首战，虽然阿豪

最近状态不错，但尊老的传统不可不守。于是，在比赛最初的7分钟里，林书豪只有一次出手，在4分03

秒史蒂夫-诺瓦克换下小斯后，阿豪才连续出手拿下4分。

从阿豪的进攻身手来看，他的状态应该说还是不错的：第一节还有3分11秒，林书豪运球过半场，

随后一记体前变向晃开何塞-卡尔德隆，然后从右路直切篮下，最终凭借速度优势探出半个身位，右手舔

篮拿下2分。从这次的进攻选择和对切入时机的判断来看，阿豪的状态和此前五场并没有太多区别。

但不可否认，猛⻰对林书豪的研究还是相当透彻的。猛⻰的策略是封住林书豪的个人进攻。尼克斯

的打法是用内线球员为林书豪做掩护，随后林书豪和内线球员双双向内线沉，找到最好的进攻机会。然

而在本场比赛，猛⻰很好的对尼克斯的内线有很好的防守——小斯，他们是让埃德-戴维斯贴身；对于泰

森-钱德勒，则是尽力往外顶；对于贾里德-杰弗里斯，则是放空。但不管怎么防守，都一定要对林书豪

进行高位双人关门包夹，至少也是假包夹，即高位的另一位防守球员时刻关注林书豪的动向，给出抢断

威胁。

简单地说，猛⻰的套路就是堵两头——林书豪和小斯；放中间——放空中距离，无论是钱德勒，还

是林书豪，还是杰弗里斯，只要离开内线，都可以放。于是，我们看到阿豪在第二节开场2分钟内连续被

抢断3次，整个上半场9投4中，只有9分入账，但出现了5次失误。

但客观来说，猛⻰的防守策略虽然不错，但个人防守能力却有⽋缺，因此还是给了林书豪很多的秀

个人能力的机会：第三节还有4分16秒，林书豪再度在罚球线处接球，但此时进攻时间只有5秒了，在这

种情况下，阿豪再也不敢轻易相信队友，于是他直接运球扛住卡尔德隆杀到篮下，然后作出起跳的假动

作，卡尔德隆面对阿豪丝毫不敢大意，毫不犹豫地跳了起来，谁知道阿豪只是轻轻收球，斜跨一步，闪

出空间后抛射打板拿到2分。

在第四节还有9分49秒时，林书豪更是趁猛⻰落脚未稳，毫不讲理地用速度强突卡尔德隆，让猛⻰

的内线火锅王戴维斯毫无用武之地，最终凭借惊人的腰腹力量，在身体⻜过篮板的情况下反向弯腰完成

高难度抛射打板。这一球也让卡尔德隆十分无奈——他已经跟着林书豪冲出了底线，但没想到这个黄色

奇迹居然能用如此逆天的手段终结进攻。

全场比赛最精彩的一球无疑发生在第四节：1分14秒，德玛尔-德罗赞突破，但空间被尼克斯封死，

随后的绵软出手被泰森-钱德勒一掌封盖。而林书豪在拿到球权后，杀到前场三分线弧顶，然后将球交给

伊曼-山姆珀特，而这位菜⻦也知情识趣，马上又将球交还给阿豪，而这时的阿豪，已经完全切换了狂战

士状态，只见他在三分线外突然作出投篮动作，全场比赛至少被骗了4次的卡尔德隆再度上当，一下子⻜

扑出三分线，而林书豪则俯身，运球直奔内线，斜身起跳躲开约翰逊的封盖，再度将球打进，并搏到约

翰逊的犯规！此时的比分是84-87！林书豪打进上篮之后，比分变成86-87，而他加罚命中后，尼克斯

终于追平了比分！

然而，更让人窒息的表演还在后面：全场比赛还有21秒结束时，山姆珀特投篮不中，但钱德勒拼死

抢到前场篮板，随后交到林书豪手中。这时，比赛还有20秒。所有尼克斯球员拉开，给中路留出足够的

空当，毫无疑问，这是属于巨星的舞台——包括小斯在内，所有球员都将目光投向林书豪，这一刻，所

有人都是看客，亿万双眼睛都在看着林书豪，看着他和卡尔德隆的一对一——但是，林书豪的举动超出

了所有人的预计，他没有选择自⼰最擅长的切入，甚至没有选择突分——他在弧顶干拔，起跳，出手，

三分，⽪球应声入网！在那一刻，林书豪根本没有看对手，他骤然转身，绷紧全身的肌肉，发出一声怒

吼！在那一刻，人们仿佛看到了吉尔伯特-阿里纳斯灵魂附体！

终场前0.5秒的绝杀，第四节单节12分的个人秀，几乎凭一⼰之力扭转了落后17分的巨大分差，在

这一刻，一切语言都是苍白的，林风暴不仅没有消弭，反而愈演愈烈，或许，用奇迹来称呼他，已经是

一种贬低——自受到重用以来，林书豪带领尼克斯六战六捷，或许，他应该考虑一下“零输豪”这个绰

号。
