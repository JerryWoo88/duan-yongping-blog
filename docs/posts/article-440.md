# 【转载】肯定天堂（二四）飘荡在马赛马拉的天空里

<div class="article-meta">第 440 篇 · 2013-03-17 13:11:04</div>

<a class="source-link" href="http://nteswjq.blog.163.com/blog/static/126998120132171114774" target="_blank" rel="noreferrer">原博客链接</a>

跨入即将腾空的热气球篮，所有的期待在离地的那刻归零，我将以我的亲眼所见来谱写我心底关于东非天堂的定义。热气球缓缓升起，大地渐渐远离我而去，我眼底的那个草原的清晨披上了层粉红的薄纱。已经有许多⻝草动物在觅⻝了，斑马、⻆马、瞪羚……这些几乎随处可见的动物在此刻幻化成极小的圆点，或深或浅，恰如一颗颗珍珠点缀在这⽚草毯之上，偶尔几枚，偶尔成⽚，都在这晨光的笼罩下隐约清丽。热气球依靠喷灯对气球内的空气加热，而令其与外界空气产生密度差，从而达到缓慢上升的结果。但因为这密度差别很小，所以热气球虽然也有仪表盘操控方向，但一旦遇到大风时，基本上是失效的。所以，在清晨的大草原上空飘荡，富有经验的舵手一定会随风而动，只需控制高度即可。这样一来，站在篮子里的我也就不用预想下一秒的眼底会出现什么动物，而将这一切选择权交给了风⼉，它愿意让我看到什么便吹我去那个⻆落吧。当太阳渐高，阳光渐猛，将眼底照得透亮，大草原依光照⻆度呈现出明黄与翠绿之色，更多的动物开始从四面八方的灌木丛或树林里走了出来。我看见一只自由自在的长颈⿅刚刚从饮水的河边回来，它欢快的步伐似乎还配合哼着小调；一个大象家庭在奔跑了一会停在草丛里，边用象⿐卷起丰美的草边与家庭成员嬉戏玩耍；那棵孤独的金合欢的平顶之上，站着一群孤傲的秃鹫，它们注视着清晨大草原上的一举一动，饿了一夜的它们目光里透出蠢蠢欲动；在不远处，还有一⽚瞪羚在吃草，它们警惕异常，却对眼前我们这个巨大的热球露出毫无恐惧的惊奇表情；当那⽚⿊白纹的斑马尽现眼底时，它们满满地占据了河岸草场，令我脚底的这⽚大草原熠熠生辉；还有那些难以忘怀的奔跑着的⻆马，永不知疲惫地将一生中的大部分时光挥霍在了迁徙途中……这，足以够成我梦想里的那个马赛马拉，足以用亲眼所见来填满那⽚从小无数次在《动物世界》里看到过的大草原。这是人类出现前地球本应有的样子，万物生长，春去春回，缺少了人类的干扰，这里的生命得到最原本的尊重，它们正是主宰这里的主人，虽然相克相生，却物竞天择，构成这⽚土地最美的风景。若不是那个倒映在大草原上的热气球的阴影常常出现底眼，我定会忘记我正飘荡在非洲的上空，而误以为这只是一个消失了的梦里的天堂。清晨⻝草的斑马一群雌瞪羚这只小雄瞪羚惊奇地望着我乘坐的热气球 一群雌鸵⻦平顶合欢上休息着一群秃鹫一只饮水归去的长颈⿅这⽚珍珠般的白点是斑马斑马与⻆马常常混合而群水源边的斑马群⿊点的是⻆马马拉河的支流一棵美丽的树影  金合欢灌木林中的长颈⿅群灌木丛中混合着⻆马与斑马 一只大雁⻜过大草原几头大象 水源边的象群排成一线的⻆马群⻆马与斑马一起迁徙热气球阴影下的⻆马群热气球阴影下的斑马
