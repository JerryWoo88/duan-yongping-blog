# 如何看到回复

<div class="article-meta">第 447 篇 · 2013-04-05 07:40:12</div>

<a class="source-link" href="http://nteswjq.blog.163.com/blog/static/126998120133574012747" target="_blank" rel="noreferrer">原博客链接</a>

这个博客以问答为主，大家可以通过下面办法查到每条回复而不用一篇一篇博文翻看：进入这个博客后，点击“关于我”，然后在左侧栏里点“评论”，就能看到按时间逆序排列的所有评论了（包括博主回复）。这个办法的缺陷是只看到回复但看不到问题，所以想看问题则需要点进博文查看。
